Link Note — Privacy Policy

Publisher: Pixelvault Labs
Last updated: 27 September 2026

Link Note is built on a simple principle: your browsing data is yours.

What we collect

Nothing. Link Note does not collect, transmit, sell, or share any personal data or browsing information. There is no account system, no analytics, no tracking pixels, and no remote server. Link Note makes zero network requests.

What Link Note does with your links

When you open the Link Note popup, it reads the current tab's address and title so it can show you a cleaned version of the link. If you paste a link instead, only the text you paste is used. Cleaning happens entirely in your browser: known tracking parameters (such as utm_*, fbclid, gclid) are stripped from the address while the rest of the link is left intact. Copying a clean link, Markdown link, or source note writes to your clipboard — nothing is uploaded anywhere.

Link Note stores nothing between uses. If you uninstall Link Note, there is no stored data to remove.

Permissions we request and why

  • activeTab — to read the address and title of the tab you have open when you click Link Note, so the popup can show and clean that link.

Link Note requests no host permissions: it cannot read the content of the pages you visit — only the address and title of the active tab while the popup is open — and even those never leave your device.

Changes

If this policy ever changes, the updated version will ship with the extension and the "Last updated" date above will be revised.
